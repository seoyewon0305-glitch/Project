- 장소: 충남 아산시 음봉면 월랑길 17 음봉 장수마을회관
- 공연개요


**학생 주도 기획·실행**


학생들을 필두로 문화 교류의 폭을 넓히고자 하였습니다.


음악회 준비 과정, 인터뷰, 공연 등을 직접 촬영과 편집을 하며, 
다양한 디지털 플랫폼에 업로드하였습니다.


**주민과의 문화적 소통**


지역 주민들과 직접적인 소통 및 교류를 진행하였습니다.


공연 전 워크숍, 사전 인터뷰, 공연 후 주민과의 대화를 통해,
깊이 있는 문화적 소통을 진행하고자 하였습니다.


**외국인 합창단 공연**


외국인 합창단을 섭외하여 다양한 문화권의 예술요소를 적극적으로 융합하였습니다.


합창단은 각 국가별 전통의상을 입고,우리나라
노래를 부르며 공연을 하였습니다.


- 역할


저는 공연의 총괄 프로듀서를 맡았습니다.


공연의 전반적인 기획을 담당하였으며, 총괄로서 팀원들을 통솔하는 역할도 하였습니다.


또한, 공연 당시의 영상을 제작하였습니다.
